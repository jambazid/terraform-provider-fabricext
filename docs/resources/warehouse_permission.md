# fabricext_warehouse_permission (Resource)

!> **Deprecated:** This resource was tombstoned in v0.3.0 and is scheduled for removal in v0.4.0. Microsoft Fabric does not offer public item-sharing REST endpoints for Warehouses. Item-level sharing must be configured using the Fabric web portal interface, and fine-grained data access should be implemented using in-database T-SQL permissions (`GRANT`/`REVOKE`/`DENY`). Creating or updating this resource fails without making network calls. Removing it from Terraform configuration is safe and makes no API calls.

!> **Warning:** **Experimental Provider**: The `fabricext` provider is published in a pre-`v1.0.0` experimental state to facilitate automated packaging and supply-chain verification. For core workspace and item management, use the official Microsoft [`microsoft/fabric`](https://registry.terraform.io/providers/microsoft/fabric/latest) provider.

Manages item-level sharing and permissions on a Microsoft Fabric **Warehouse** (`read`, `write`, `reshare`) for a Microsoft Entra principal.

## Deprecation & Migration Guide

Microsoft Fabric does not expose public REST routes for declarative Warehouse item sharing. Consequently, item-level sharing cannot be managed declaratively through the Fabric REST API at this time.

### Recommended Access Architecture

1. **Item Connectivity**: Share the Warehouse through the Microsoft Fabric web portal UI, granting the principal **Read** connectivity.
2. **Fine-Grained Authorization**: Connect to the Warehouse TDS endpoint (port 1433) as an administrator and execute granular T-SQL statements:
   ```sql
   -- Users are created implicitly upon GRANT in Fabric Data Warehouse
   GRANT SELECT ON SCHEMA::finance TO [SEC-Fabric-Finance-Analysts];
   ```

Refer to the [Access Control Playbook](../guides/access_control_playbook.md) for full scenario walkthroughs.

### Required

- `principal_id` (String) Microsoft Entra Object ID (UUID) of the principal receiving access.
- `role_type` (String) Permission role to grant on the Warehouse. Valid values: `read` (`Read`), `write` (`Read`, `Write`), `reshare` (`Read`, `Reshare`). When reading existing permissions from Fabric, multi-permission assignments are collapsed according to precedence: `write` > `reshare` > `read`.
- `workspace_id` (String) UUID of the Microsoft Fabric workspace containing the Warehouse.

### Optional

- `principal_type` (String) Microsoft Entra principal type. Valid values: `User`, `Group`, `ServicePrincipal`, `ServicePrincipalProfile`. Defaults to `Group`. Normalized to TitleCase upon import or read.
- `warehouse_id` (String) Resolved or explicitly specified UUID of the Microsoft Fabric Warehouse. At least one of `warehouse_name` or `warehouse_id` must be specified.
- `warehouse_name` (String) Display name of the target Microsoft Fabric Warehouse. At least one of `warehouse_name` or `warehouse_id` must be specified.

- `id` (String) Composite resource identifier in the format `{workspace_id}/{warehouse_id}/{principal_type}/{principal_id}`.
