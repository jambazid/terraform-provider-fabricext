# fabricext_sql_database_permission (Resource)

!> **Deprecated:** This resource was tombstoned in v0.3.0 and is scheduled for removal in v0.5.0. Microsoft Fabric does not offer public item-sharing REST endpoints for SQL Databases. Item-level sharing must be performed using the Share quick action in the Fabric web portal, and fine-grained data access should be implemented using in-database SQL roles or Microsoft Purview policies. Creating or updating this resource fails without making network calls. Removing it from Terraform configuration is safe and makes no API calls.

!> **Warning:** **Experimental Provider**: The `fabricext` provider is published in a pre-`v1.0.0` experimental state to facilitate automated packaging and supply-chain verification. For core workspace and item management, use the official Microsoft [`microsoft/fabric`](https://registry.terraform.io/providers/microsoft/fabric/latest) provider.

Manages item-level sharing and permissions on a Microsoft Fabric **SQL Database** (`read`, `read_data`, `read_spark`, `write`, `reshare`) for a Microsoft Entra principal.

## Deprecation & Migration Guide

Microsoft Fabric does not expose public REST routes for declarative item sharing on Fabric SQL Databases.

### Recommended Access Architecture

1. **Item Connectivity**: In the Microsoft Fabric web portal, locate the SQL Database and select the **Share** quick action, granting minimum read access.
2. **Database Roles**: Connect over TDS to the database endpoint and assign users to native database roles:
   ```sql
   CREATE USER [app-backend-spn] FROM EXTERNAL PROVIDER;
   ALTER ROLE db_datareader ADD MEMBER [app-backend-spn];
   ```

Refer to the [Access Control Playbook](../guides/access_control_playbook.md) for full scenario walkthroughs.

### Required

- `principal_id` (String) Microsoft Entra Object ID (UUID) of the principal receiving access.
- `role_type` (String) Permission role to grant on the SQL Database. Valid values: `read` (`Read`), `read_data` (`Read`, `ReadData`), `read_spark` (`Read`, `ReadAll`, `SubscribeOneLakeEvents`), `write` (`Read`, `Write`), `reshare` (`Read`, `Reshare`). - `workspace_id` (String) UUID of the Microsoft Fabric workspace containing the SQL Database.
